# Security Policy

## Supported versions

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | Yes                |
| < 0.1   | No                 |

## Reporting a vulnerability

**Do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

### Preferred: GitHub private vulnerability reporting

Use the repository's private reporting form:

https://github.com/rabitem/outcome-metrics/security/advisories/new

### Fallback contact

If private reporting is unavailable, email **huisingafelix@gmail.com** with:

- description of the issue
- steps to reproduce
- impact assessment if known

You should receive an acknowledgement within a few days. Please allow time for a fix before public disclosure.
